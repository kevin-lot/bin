# AGENTS.md

Personal shell scripts on `$PATH`, one executable per file, no extension.

- `bin_install_update` — installs/updates two machines only: professional MacBook (`darwin`) and personal Fedora PC (`fedora`).
- Variables: UPPERCASE for globals, lowercase for `local`.
- Follow `.editorconfig`.
- Scripts like `docker_clean`, `reset_jetbrains` are destructive — read before running, confirm first.
